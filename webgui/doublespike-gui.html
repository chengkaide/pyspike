蒙特卡洛验证

1. 双稀释剂法要解决什么问题

质谱测量中，同位素比值会因为质量分馏而系统偏移。若测量一套样品–稀释剂混合样， 稀释剂本身提供了“内标”：它的加入量已知，只要能从混合样的比值里同时解出 稀释剂比例、样品自身的天然分馏和仪器造成的分馏， 就可以把分馏完全校正掉，而不需要假设样品的分馏遵循某个已知定律。

模型有三个未知量，恰好被四个（或更多）同位素提供的三个独立比值确定：

λ·Tᵢ + (1 − λ)·Nᵢ = Mᵢ (式 10) Nᵢ = nᵢ·exp(−α·Pᵢ) 样品（含天然分馏 α） Mᵢ = mᵢ·exp(−β·Pᵢ) 实测（含仪器分馏 β） Pᵢ = ln(Mⱼ / Mₖ) 该比值对应的原子质量对数比

n 是未稀释标样，T 是稀释剂，m 是实测混合样， λ 是稀释剂在比值空间中的比例。三个方程、三个未知量， 因此这是一个非线性方程组，需要迭代求解。

2. 本工具箱换了什么迭代模型

原版把式 (10) 整理成未知量 y = (λ, (1−λ)α, β)，用线性化结果当初值，再交给 SciPy 的 fsolve（MINPACK hybrid）。它有四个实际问题：

  • 1/(1−λ) 的重参数化在 λ→1（稀释剂为主）时病态；
  • fsolve 需要 Jacobian 且没有下降性保证，可能停在错误解上，只打印一条警告就返回；
  • 一次只能算一个测点，蒙特卡洛几千次会很慢；
  • 初值用一个启发式“上限 1/|P|”来兜底，缺少原则性。

新算法：消去 λ 的二维阻尼牛顿

式 (10) 对 λ 是线性的。记 Sᵢ = Tᵢ − Nᵢ、Uᵢ = Mᵢ − Nᵢ， 则 λ·Sᵢ = Uᵢ。对任意试算的 (α, β)，由不同比值给出的 λ 必须一致， 于是 λ 被完全消掉，只剩两个未知量：

Gₓ(α, β) = S_{i₀}·Uₓ − U_{i₀}·Sₓ = 0 x 取另外两个比值 λ = U_{i₀} / S_{i₀} 收敛后直接算出，无需再用 1/(1−λ)

其中 pivot i₀ = argmax|T − n|，即稀释剂影响最大的那个比值，它离退化点 S=0 最远。

对这个 2×2 系统做牛顿迭代，配三件保证收敛的措施：

  • 解析 Jacobian（对 G 逐项求导，无差分近似）；
  • 保方向的步长限制——整步等比缩放而非逐分量截断，否则会破坏下降性；
  • 回溯线搜索，以残差的绝对极大范数为价值函数，下降不足就折半；
  • 收敛判据用相对残差 |G| / (|S·U| + |U·S|)，这样 48Ca/42Ca 这种量级 500 的比值和 0.1 量级的比值判定标准一致；
  • 失败时从一组物理上合理的 (α, β) 网格重启，最后才回退到 fsolve。

因为所有运算都是逐元素的，整批测点可以一次迭代，实测效果：

3. 误差是怎么传播的

精度评估不需要数值迭代，而是把式 (10) 在解附近线性化，用附录 A 的公式一步算出。 噪声模型（式 34）：

σᵢ² = a + b·Iᵢ + c·Iᵢ² a = 4·k·T·R_ref² / (Δt·R) Johnson–Nyquist 噪声 b = e·R_ref / Δt 计数统计（散粒噪声）

再由 z = (λ, α, β) 对输入的导数合成协方差（式 16/23/30）：

V_z = (∂z/∂n)·V_n·(∂z/∂n)ᵀ + (∂z/∂T)·V_T·(∂z/∂T)ᵀ + (∂z/∂m)·V_m·(∂z/∂m)ᵀ 报告误差 = √(V_z)[1,1] α 的 1SD ppm/amu = 10⁶·误差 / 平均原子质量 式 51，便于横向比较

本页所有曲线与彩色图都是这个公式在 (p, q) 平面上的取值。绿色区域就是“这个稀释剂在这个比例下最准”的地方。

4. 怎么选稀释剂

  • 选哪两个同位素：一般挑质量差尽量大、且彼此不受同质异位素干扰的一对。程序在“最优稀释剂”页穷举所有配对并排序。
  • 混合比 p：由图上的谷底给出，通常在 0.3–0.6 之间；偏离谷底 10% 通常只让误差增加百分之几，但掉到 0.05 或 0.95 会急剧恶化。
  • 稀释剂本身的分馏：稀释剂若没标定好，误差会直接进入 α。可用“数据反演”页的“把标样误差计入”来评估这部分贡献。
  • 不要只看 α 误差：如果关心的是某个具体比值（如 ⁹⁸Mo/⁹⁵Mo），在“误差目标”里切换成该比值，最优稀释剂会随之改变。
